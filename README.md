# 🔮 Amethyst Menu — Web UI

A modern dark-purple web interface built with HTML5, CSS3, and JavaScript. Ready for 1-click deployment on **Vercel**.

![Amethyst Banner](https://files.catbox.moe/71znnd.jpg)

## ⚡ Live Vercel Deployment

Deploy this project to Vercel in 1 click or via CLI:

### Option 1: Vercel Web Dashboard
1. Push this repository to **GitHub**.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Select this GitHub repository and click **Deploy**. Vercel will automatically detect `index.html` and deploy it instantly!

### Option 2: Vercel CLI
```bash
npm install -g vercel
vercel
```

---

## 💻 Local Preview

To test locally:
```bash
npm run dev
```
Or simply open `index.html` directly in your browser.

---

## ✨ Features

- **Responsive Modern UI**: Purple HSL dark theme with smooth glassmorphism.
- **Interactive Controls**: Click rows, toggles, or press `F9` to show/hide the menu.
- **Fixed High-Res Banner**: 1408x768 aspect-fit crystal banner.
- **Notifications & Modals**: Built-in toast notifications and input overlays.
